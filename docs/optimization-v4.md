# 南京江心洲3D时空 · V4 全面优化

更新时间：2026-08-11

## 验收目标

- 地图首屏优先，首次访问不被任务弹窗遮挡。
- 修复区域总览中的黑色拉丝与三角形渲染异常。
- 桌面端按主题切换详情；移动端使用紧凑工具栏和可收起详情面板。
- 地标、站点、桥梁、道路、河流和经纬度标签根据镜头距离统一避让。
- 中英文完整，主要文字不低于 12px，主要触控目标不低于 44px。
- 保留现有空间数据、Blender 模型、探索进度和正式访问地址。

## 已确认问题

1. 区域土地多边形在当前 WebGL 宽线组合下出现大面积黑色拉丝。
2. 首次进入的全屏探索简报遮挡地图。
3. 任务、交通、桥隧、地标和证据在侧栏同时展开，信息层级过重。
4. 手机端视角按钮被截断，HUD、地图标签和控制按钮互相争抢空间。
5. 多处 6–9px 字号不适合公众浏览和触控设备。
6. Three.js 控制器仍触发 `THREE.Clock` 弃用警告。
