# 南京江心洲交通实时层 V10 工作记录

## 目标

先以本地确定性模拟数据实现公交与地铁的实时状态体验：车辆位置、线路状态、预计到站、更新时间和数据新鲜度。后续获得授权数据源后，仅替换服务端 provider，不改变 Three.js、UI 或现有静态线路数据。

## 当前决策

- 默认模式：`simulated`。
- 浏览器只请求 `/api/transit/realtime`，不直接访问外部交通平台。
- 交通图层关闭时停止轮询；接口失败时继续显示模拟状态并标记回退。
- 实时位置、到站和状态均不进入多人房间快照。

## 验收

- 公交、地铁均可显示状态与预计到站。
- 3D 车辆沿现有线路平滑运动。
- 中英文、移动端、交通图层开关和既有模拟交通保持兼容。
- `npm run transit:validate`、`npm run lint`、`npm test`、`npm run build` 通过。

## 待后续接入

- 获得南京公交/地铁运营方或授权第三方的实时 HTTP/JSON 或 GTFS-Realtime 数据后，实现 `TransitRealtimeProvider` 的 live adapter。
- 不抓取、破解或重新分发 App 内部接口。

## 后续视觉修正记录

江豚层首次验收发现默认水系关闭且真实比例模型在全岛镜头下不可辨认。修正为默认显示水系，并增加低对比度水面活动波纹；GLB 仍保持真实米制比例，近景继续显示详细模型。
